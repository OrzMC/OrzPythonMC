Install · Uninstall

安装与卸载

无需 Python / pip。Windows 用 PowerShell,其余平台用 curl;重复执行安装即升级,装好后也可用内置 orzmc update 自升级。

macOS / Linux curl -fsSL https://orzmc.github.io/OrzPythonMC/install.sh | sh
Windows · PowerShell irm https://orzmc.github.io/OrzPythonMC/install.ps1 | iex
卸载 · 全平台 orzmc self-uninstall --yes

安装自动识别平台、登记 PATH;卸载删除二进制、还原 PATH,游戏数据默认保留(--remove-root 一并删除)。--version vX.Y.Z 可固定安装版本。

Quickstart

快速开始

安装后直接命令行使用;版本缺失时自动下载补齐,无需单独的 install 步骤。

# 安装(Unix 一条命令;Windows 用 irm https://orzmc.github.io/OrzPythonMC/install.ps1 | iex)
curl -fsSL https://orzmc.github.io/OrzPythonMC/install.sh | sh

# 每个子命令支持 --help 查看参数(如 orzmc client --help 可看到 -u/--username 等)
orzmc client --help

# 启动最新版(26.2)原版客户端;-v 缺省时自动用 Mojang 最新 release
# -u 自定义玩家名(默认 guest;TTY 未指定时交互询问,回车用默认)
orzmc client -v 26.2 -u Steve
orzmc client -v 26.2

# 以 Fabric 启动客户端
orzmc client -v 26.2 -t fabric -u Steve

# 部署并启动 Paper 服务端(自动接受 EULA,无窗口模式)
orzmc server -v 26.2 -t paper --yes --nogui

# 元数据(版本清单 / Fabric / Paper / Forge)默认缓存 24h;--refresh 强制重新拉取
orzmc client -v 26.2 --refresh

# 下载并发(小文件多、延迟高 / 走代理时调大明显更快,1-64,默认 16)
orzmc client -v 26.2 -j 32

# 升级 orzmc 自身(GitHub 最新发布;--check 只查询,-v 指定版本)
orzmc update --check
orzmc update
Features

项目特性与价值

OrzMC 把启动器的重复工作收进一个包:依赖管理、Java 托管、多版本并存、服务端部署,都是开箱即用。

🗂️

多版本并存

客户端 / 服务端一版本一目录,互不干扰;一台机器轻松切换任意版本与类型。

☕

Java 运行时沙盒

按版本自动下载所需 JRE 并托管到应用目录,不依赖系统 Java,版本要求自动判定。

⌨️

交互式版本选择器

全屏键盘导航:方向键选择、输入即过滤、正式版 / 测试版一键切换,回车即启动。

🖥️

服务端部署一键化

自动接受 EULA、写入配置;支持 vanilla / Paper / Fabric / Forge,--nogui 无窗口启动、stop 或 Ctrl-C 优雅关闭。

🌍

六平台全覆盖

macOS / Linux / Windows × x86_64 / arm64,为每个平台构建独立二进制,发布即用。

🚀

即装即用

检测到文件缺失自动下载补齐,无需独立 install 子命令;CLI 与库双层架构,可编程复用。

💾

元数据缓存与进度反馈

版本清单 / Fabric / Paper / Forge 元数据统一缓存 24 小时,离线也能启动已装版本;下载与元数据请求都有进度条(百分比 + 计数),慢网不静默;需要最新数据时加 --refresh。

⚡

下载并发可调

资源阶段是几千个小文件,耗时由每请求延迟与并发数决定而非带宽。连接池随并发自动放大,延迟高的链路上 -j 32 可成倍提速(实测约 2.2 倍);客户端 jar / JRE 等大文件自动 4 路分段并行下载(实测 1.6 倍),服务器不支持分段时自动回退。

⬆️

命令行自升级

orzmc update 一键升级工具自身:--check 先看有没有新版,-v 指定版本或绕过 GitHub 限流,--file 离线安装;pip / pipx 安装会自动识别并提示用包管理器升级。
